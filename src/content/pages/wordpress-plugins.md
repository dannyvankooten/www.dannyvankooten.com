title: "WordPress plugins"
---

WordPress plugins I built over the years. Some are still active, some are archived.

Together, these plugins have been used on millions of websites.

### Mailchimp for WordPress

A WordPress plugin that connects a site to Mailchimp. It started as a small open-source plugin and grew into my main product.

[Website](https://www.mc4wp.com/) [WordPress.org](https://wordpress.org/plugins/mailchimp-for-wp/) [GitHub](https://github.com/ibericode/mailchimp-for-wordpress)

---

### Koko Analytics

Privacy-friendly analytics for WordPress. It keeps all data on the website’s own server and only tracks aggregated counts.

[Website](https://www.kokoanalytics.com/) [WordPress.org](https://wordpress.org/plugins/koko-analytics/) [GitHub](https://github.com/ibericode/koko-analytics)

---

### Boxzilla Pop-ups

A lightweight pop-up plugin for WordPress, with trigger rules for showing messages at the right time.

[Website](https://boxzillaplugin.com/) [WordPress.org](https://wordpress.org/plugins/boxzilla/)

---

### Change Username

Change WordPress usernames from the user edit screen, with validation for existing users, illegal logins, and Multisite superadmin rights.

[WordPress.org](https://wordpress.org/plugins/change-username/)

---

### ~HTML Forms~

A WordPress plugin for creating multipurpose forms and handling submissions in a safe and extendible way. I sold this plugin to Link Software LLC in 2024.

[Website](https://www.htmlformsplugin.com/) [WordPress.org](https://wordpress.org/plugins/html-forms/)

---

### Widget Blocks

A plugin for using the block editor in classic widget areas, before WordPress core shipped block widgets.

[WordPress.org](https://wordpress.org/plugins/wysiwyg-widgets/)

---

### Social Sharing by Danny

A small plugin for adding social sharing links to WordPress posts without much overhead.

[WordPress.org](https://wordpress.org/plugins/dvk-social-sharing/)

---

### ~Newsletter Sign-Up~ (discontinued)

A plugin for adding newsletter sign-up forms to WordPress sites. It was later replaced by Mailchimp for WordPress.

[WordPress.org](https://wordpress.org/plugins/newsletter-sign-up/)

---

### ~Recent Facebook Posts~ (discontinued)

A plugin for showing recent posts from a Facebook page on a WordPress site.

[WordPress.org](https://wordpress.org/plugins/recent-facebook-posts/)

---

### ~Mailchimp User Sync~ (discontinued)

A plugin for syncing WordPress users to a Mailchimp list. Now part of [Mailchimp for WordPress Premium.](https://www.mc4wp.com/premium-features/)

[WordPress.org](https://wordpress.org/plugins/mailchimp-sync/)
